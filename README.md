# AI Agent

A lightweight, local-first AI agent built using Python,
LangGraph, and Ollama.

## Project Status

In Development

## Objectives

- Local LLM inference
- Stateful agent orchestration
- Tool calling
- Conditional routing
- Conversational context
- Automated testing

## Technology Stack

- Python 3.12
- LangGraph
- LangChain
- Ollama
- uv
- Pytest
- Ruff
